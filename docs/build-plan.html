Shared rules

Hand-offs (don't be late on these)

  • 16:45 Person 1 pushes the Next.js scaffold, types and sample Blueprint
  • 17:00 Person 2 pushes the Groq wrapper
  • 21:30 Person 3's agents and tests plug into Person 2's runner; Person 1's Approve button sends the final Blueprint
  • Until a hand-off lands, use a fake version and keep going

Working together

  • Agree on the types in lib/types.ts by 17:00, then don't change them without telling the others
  • Push small commits often; each person works in their own files
  • Blocked for more than 20 minutes? Say so in the group chat

Groq limits

  • At most 2–3 model calls at once, because of per-minute rate limits
  • Short prompts: each agent gets only what it needs
  • Keep a fallback model name in config

If behind at 01:00, cut in this order

  1. Parliament debate pass: keep the single review round
  2. Fix loop: just run tests and show results
  3. Parallel agents: run tasks one at a time
  4. Live preview: show files and passing tests
  5. Never cut Discovery or the Blueprint

Demo script (3 minutes)

  1. "A marketplace for second-hand textbooks." Answer as non-technical
  2. The parliament reviews the idea; its questions come back in simple words and the confidence meter rises
  3. Approve; agents leave each other notes on the task board
  4. QA catches the double-buy bug, backend fixes it, the test turns green
  5. Open the marketplace and buy a book
