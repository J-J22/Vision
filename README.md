# Vision

A platform where a team of AI agents takes an app idea from first conversation to a deployed website.

1. **Discovery**: agents learn about the user's background, then ask questions at the user's level until every technical detail is covered (pages, database, APIs, auth, payments, hosting).
2. **Blueprint**: the answers become one structured technical plan that the user approves.
3. **Team build**: specialist agents (backend, frontend, database, QA, devops) pick up tasks from a shared board and coordinate like coworkers.
4. **Test & break**: agents hunt for edge cases and fix the failures they find.
5. **Deploy**: ship to staging, then to production.

Built for a 24-hour hackathon. The first test case is a marketplace app.
